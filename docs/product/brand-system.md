# Nusa Creator Studio brand system

## Product name

Nusa Creator Studio

## Positioning

Nusa Creator Studio is a mobile-first AI content studio for social commerce creators. It helps creators plan and generate product scripts, captions, voiceovers, try-on concepts and vertical video workflows from one focused workspace.

## Logo and icon direction

The brand direction uses a compact gradient N mark paired with a clean Nusa Creator Studio wordmark. The mark should feel energetic, creator-friendly and premium without becoming visually noisy.

Guidelines:

- Use the full wordmark when space allows.
- Use the compact Nusa label on very small screens when the full wordmark would crowd navigation or account controls.
- Keep the N mark large enough to remain readable in the app header.
- Prefer SVG source assets during the MVP phase; final exported production assets can be added later.

## Preferred app icon

The preferred app icon is the light-background variant: a rounded light square with the centered gradient N mark.

Current icon files:

- `apps/web/public/favicon.svg` ? browser tab favicon.
- `apps/web/public/app-icon.svg` ? preferred app icon reference, using the light-background gradient N direction.
- `apps/web/public/app-icon-light.svg` ? explicit light-background variant kept for clarity/reference.
- `apps/web/public/apple-touch-icon.svg` ? Apple touch icon placeholder, aligned with the light icon direction.

## Color palette direction

The app remains dark-first and premium. The palette uses deep navy/slate surfaces, subtle glass borders and a creator-energy gradient across cyan, purple, coral and warm orange.

Intentional light contrast is reserved for:

- primary CTA buttons;
- preferred app icon background;
- selected or featured surfaces;
- small premium highlights where clarity matters.

Avoid turning the product into a full light theme or adding random white panels that break the dark studio feel.

## Typography direction

The UI uses a modern sans-serif stack with a strong, rounded, high-confidence feel. Headings should be bold and tightly tracked enough to feel like a creator product, while body copy should remain readable and calm.

Hero typography can use responsive sizing and tight line-height. Form labels, metadata and badges should stay compact and consistent.

## Mobile header rule

On very small screens, a compact brand label such as `Nusa` is acceptable. The full `Nusa Creator Studio` wordmark should appear when there is enough horizontal space.

This keeps the header usable while preserving brand recognition.
